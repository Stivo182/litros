# SQLite Pool Review Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Исправить четыре дефекта SQLite-пулов, найденные ревью, не изменяя пакет `entity`.

**Architecture:** Один singleton-пул Autumn владеет всеми слотами приложения. Каждый рабочий SQLite-менеджер получает уникальную исходную строку соединения через игнорируемый URI-фрагмент, поэтому глобальный cache `entity` разделяется по слотам; сам пул отдельно различает насыщение и полную потерю ёмкости и допускает передачу права на закрытие.

**Tech Stack:** OneScript 2.1, Autumn 4.3, entity 3.4.3.1, System.Data.SQLite, OneUnit, asserts, moskito.
