# Устойчивый фасад менеджера сущностей — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить единый отказоустойчивый фасад CRUD/SQL над `entity`, повторяющий транзакции целиком и исключающий обход pipeline из прикладного кода.

**Architecture:** `УстойчивыйМенеджерСущностей` имеет ровно шесть экспортных прикладных методов и направляет вызовы через singleton `ИсполнительОперацийБД`, передавая executor только внутренние не-Autumn адаптеры. `КонтекстУстойчивогоМенеджераСущностей` потокобезопасно хранит табакерку, один лениво разрешённый raw manager и общую фатальную диагностику; простую и транзакционную попытки выполняют соответственно `ОперацияУстойчивогоМенеджераСущностей` и `ТранзакционнаяОперацияМенеджераСущностей`. Внутри транзакционного callback выдаётся короткоживущая `ЕдиницаРаботыБД`; неудачный rollback атомарно блокирует также уже ожидающие executor-слота операции маркером `litros_db_rollback_failed:`.

**Tech Stack:** OneScript 2.x, Autumn 4.3, entity 3.4.3.1, resilience 0.3, moskito 0.4.1, OneUnit 0.4, System.Data.SQLite.

Менеджер = Мок.Получить(Тип("МенеджерСущностей"));
